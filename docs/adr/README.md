# Architecture Decision Records

One short document per significant decision. Never delete an ADR — supersede it
with a new one and link back.

- Numbering: 4-digit sequence (0001, 0002, ...)
- Status: Proposed -> Accepted -> (Superseded by ADR-XXXX)
- Keep each ADR under one page.
